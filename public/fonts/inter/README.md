# Inter local

`inter-latin-wght-normal.woff2` procede de `@fontsource-variable/inter` versión 5.2.8, distribuido en el registro npm. Se conserva la licencia SIL Open Font License en `LICENSE`.

La fuente variable Latin incluye los caracteres españoles. Se carga localmente con `@font-face` y preload; no hay solicitudes a Google Fonts ni a servicios externos durante el uso de la tienda. El archivo pesa 48 256 bytes. Los componentes usan los pesos 400, 500, 600 y 700 del kit.

El kit declara la familia Inter, pero no incorpora un archivo de fuente. Se incluye este recurso para renderizar Inter realmente en los dispositivos que no la tengan instalada, conforme a la tipografía solicitada por el usuario.
